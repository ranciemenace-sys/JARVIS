# JARVIS — Personal AI Assistant

## About the Project

JARVIS is a personal AI assistant designed to help organize daily activities, manage projects, retrieve information and automate repetitive tasks.

The project aims to create a locally operated AI assistant with an intelligent conversational interface, persistent memory and controlled access to external tools.

## Vision

To build a personal AI assistant that acts as a central hub for productivity, learning, project management and automation.

## Technology Stack

- **Frontend:** HTML, CSS and JavaScript
- **Backend:** Python and FastAPI
- **AI Engine:** Ollama with Qwen2:7B
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Development Status

Currently developing the initial dashboard and frontend-to-backend communication.

## Planned Features

- AI-powered conversations
- Task and project management
- Persistent memory
- File management
- Gmail integration
- GitHub integration
- KCA Virtual Campus integration
- Voice interaction
- Desktop interface

## Development Philosophy

This project is being developed incrementally, with an emphasis on understanding the underlying technologies, writing maintainable code, documenting decisions and implementing security controls.

## Learning Objectives

- Develop practical Python backend skills.
- Improve HTML, CSS and JavaScript proficiency.
- Understand LLMs and AI agents.
- Learn API integration and database management.
- Build and maintain a real-world software project.
